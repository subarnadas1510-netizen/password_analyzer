# 🔐 Password Strength Analyzer

A modern and responsive **Password Strength Analyzer** built using **HTML5, CSS3 (Tailwind CSS), and JavaScript**. This web application helps users evaluate the strength of their passwords in real time by analyzing various security parameters and providing actionable feedback to improve password security.

## 📌 Features

- ✅ Real-time password strength analysis
- 🔒 Password policy validation
- 📊 Password entropy calculation
- ⏱️ Estimated brute-force crack time
- ⚠️ Weak password pattern detection
- 🎯 Password strength score and progress meter
- 🔑 Secure random password generator
- 📋 One-click copy to clipboard
- 👁️ Show/Hide password functionality
- 📱 Responsive and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript (ES6)

## 🚀 How It Works

1. Enter a password in the input field.
2. The application analyzes the password instantly.
3. It checks password length, character diversity, and common weak patterns.
4. It calculates password entropy and estimates crack time.
5. The application displays a strength score, security recommendations, and password policy status.
6. Users can also generate and copy a strong password with one click.

## 🎯 Project Objectives

- Promote cybersecurity awareness.
- Help users create stronger and more secure passwords.
- Demonstrate password analysis techniques using client-side web technologies.
- Provide a lightweight and privacy-friendly password security tool.

## 🔒 Security

This application performs all password analysis **locally in the browser**. No passwords are stored, transmitted, or sent to any server, ensuring complete user privacy.
